# 🎵 MediaPlayer-JFX

A desktop **Media Player application** built using **JavaFX**, designed to play audio and video files with a simple and interactive user interface. This project focuses on JavaFX fundamentals, media handling, and event-driven programming.

---

## 🚀 Features
- Play audio and video media files
- Play, pause, stop controls
- Media seek / timeline control
- Volume control
- User-friendly JavaFX interface
- Event-driven media handling

---

## 🛠️ Tech Stack
- Java
- JavaFX
- JavaFX Media & MediaPlayer API
- Scene Builder (if used)
- MVC-style structure (if applicable)

---

## 🧠 Project Summary
**MediaPlayer-JFX** was developed to understand desktop application development using JavaFX and to gain hands-on experience with media playback APIs. The project demonstrates handling multimedia files, UI components, and user interactions in a desktop environment.

This application can be extended further with playlist support, advanced media controls, and custom themes.
